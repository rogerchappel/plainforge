# Roadmap

## Now

- Keep the MVP deterministic and local-first.
- Improve fixture coverage for common HTML extraction edge cases.
- Make CLI reports easy to paste into issues and PRs.

## Next

- Add optional adapter hooks for comparing multiple conversion libraries.
- Add richer readability metrics without introducing network calls.
- Support fixture manifests for large suites.

## Later

- Publish curated fixture packs.
- Generate static report pages from local runs.
- Explore package-manager templates for agent workflows.

## Not planned

- Executing fixture JavaScript or loading remote resources.
- Hidden telemetry or hosted processing.
- Replacing full crawler/readability platforms.
